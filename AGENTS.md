# Portfolio animation and VFX

When a task adds or changes animation or VFX, consult the relevant upstream reference and read the installed skill's `SKILL.md` before using it. Choose tools that fit the requested effect and the existing React Three Fiber, GSAP, and SVG setup.

| Need | Reference |
| --- | --- |
| Analyze timing and motion from reference footage | [reanimate](https://github.com/NiazMorshed2007/reanimate) |
| Design UI choreography, timing, and easing | [motion-design-skill](https://github.com/LottieFiles/motion-design-skill) |
| Compare motion graphics styles and study source examples | [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15) |
| Develop illustrated and explainer motion | [huashu-art-motion](https://github.com/alchaincyf/huashu-art-motion) |
| Make hand-drawn art and animated loops in code | [anidoodle](https://github.com/alexgreensh/anidoodle) |
| Render mathematical animations offline | [Manim](https://github.com/ManimCommunity/manim) |
| Model, animate, or export 3D assets | [blender-skills](https://github.com/EL4CTEO/blender-skills) |
| Prototype real-time Three.js particles | [three.quarks](https://github.com/Alchemist0823/three.quarks) |
| Add a rendering pass to a React Three Fiber scene | [react-postprocessing](https://github.com/pmndrs/react-postprocessing) |
| Tune effect settings while developing | [Tweakpane](https://github.com/cocopon/tweakpane) |
| Composite and finish rendered footage | [EffectCraft](https://github.com/storytold/effectcraft) |
| Produce a launch film, walkthrough, or teaser | [cinetic](https://github.com/Leonxlnx/cinetic) |
| Review and polish motion graphics in a video | [motionmaxxing](https://github.com/Tejashmakwana/motionmaxxing) |

Codex skills are installed in the user's Codex skills directory. Look in the ignored `qa/animation-toolkit/` directory for the local JavaScript packages, `mg-styles-15` examples, and the portable EffectCraft build. Manim uses an isolated Python environment, and Blender uses the existing desktop installation.
